# Pyxel Suite

A browser toolkit for preparing graphics for GB Studio.

Download [the complete HTML application](https://github.com/carlofurore-bit/pyxel-suite/releases/download/v1.1.0/pyxel_suite.html) and open the saved file in your browser. Pyxel Morph and SpriteBingo share a single interface. [Browse the suite source](pyxel_suite.html).
